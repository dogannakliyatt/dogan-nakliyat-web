DOĞAN NAKLİYAT - GITHUB PAGES KURULUMU

1. GitHub'da dogannakliyatt/dogan-nakliyat-web deposunu açın.
2. index.html, robots.txt, sitemap.xml ve favicon.png dosyalarını deponun ana dizinine yükleyin.
3. images klasörünü, içindeki .webp fotoğraflarıyla birlikte yükleyin.
4. Settings > Pages > Deploy from a branch > main > /(root) > Save.
5. https://dogannakliyatt.github.io/dogan-nakliyat-web/ adresini kontrol edin.

Mevcut dosyalar varsa yenileriyle değiştirin. Resimler images klasöründe kalmalıdır.

NOTLAR:
- Fotoğraflar AI ile hazırlanmış temsili görsellerdir; gerçek aracın fotoğrafları olarak sunmayın.
- Plaka görsellerde görünüyor. İsterseniz yayına almadan önce bulanıklaştırılabilir.
- 1000+ başarılı nakliye sayısı kullanıcı tarafından sağlanmıştır; yayından önce doğrulayın.
- Google yorumları kullanıcının paylaştığı ekran görüntülerinden alınmıştır.
- Google Search Console doğrulama etiketi henüz eklenmedi.
- WhatsApp mesajı kullanıcı tarafından gönderilir, otomatik gönderilmez.
